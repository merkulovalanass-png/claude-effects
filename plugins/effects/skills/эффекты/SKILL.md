# /эффекты

Пользователь написал: `$ARGUMENTS`

## Что делать

1. **Эффект** — первое слово аргументов. Допустимые: `стекло`, `орбита`, `прожектор`, `чеклист`, `таймлайн`, `склейка`, `тумблеры` (или англ. glass, orbit, spotlight, checklist, timeline, matchcut, toggles). Если эффекта нет или он не из списка — коротко перечисли все 7 с одной строкой описания и спроси, какой.
2. **Видео** — файл, который пользователь приложил к этому сообщению (путь вида `@"/…/файл.mov"`), иначе последнее видео из разговора. Если видео нет — попроси приложить, ничего не запускай.
3. **Тексты.** Если пользователь в своих словах попросил другой текст (слово для прожектора, слово на плашке склейки, пункты чеклиста, тумблеры, ник в посте), передай это в `--set` как JSON (поля ниже). Иначе не передавай ничего — сработают настройки по умолчанию и личные из `~/.effects/config.json`.
4. **Запуск** (скрипт лежит в папке этого скилла, папка `scripts/`):
   ```bash
   python3 "<папка скилла>/scripts/run.py" <эффект> "<путь к видео>" [--set '<json>']
   ```
   Таймаут команды — 10 минут. Первый запуск дольше: ставится движок анимации (и для «орбиты»/«прожектора» — вырезка из фона). Пока идёт, напиши одну строку, что эффект готовится.
5. **Результат.** Скрипт печатает `ГОТОВО: <путь>`; файл сохраняется рядом с исходным видео как «<имя> — <эффект>.mp4». Покажи его пользователю (если есть инструмент отправки файлов — отправь файл, иначе дай ссылку на путь) и в 1–2 предложениях опиши, что происходит в кадре. Не пересказывай технические шаги.

Если скрипт упал с сообщением «нужна программа …» — передай пользователю эту подсказку по установке дословно.

## Эффекты и поля для `--set`

| эффект | что в кадре | поля |
|---|---|---|
| стекло | стеклянные карточки вокруг человека: счётчик, рендер, растущие просмотры, кольцо 4K, плашка внизу | `count`, `viewsLabel`, `sign` |
| орбита | обложки рилсов кружат вокруг головы, дальние уходят за неё | обложки берутся из папки `covers_dir` в `~/.effects/config.json` (или `~/.effects/covers`), иначе кадры из самого видео |
| прожектор | комната гаснет, человек в свете, за головой загорается неоновое слово | `word`, `color` (hex), `size` |
| чеклист | карточка «Claude монтирует ролик», пункты отмечаются по очереди | `title`, `items: [{text, note, at}]` |
| таймлайн | монтажная панель с кадрами, голосом, музыкой и бегущей светящейся линией | `texts: [[start0..1, end0..1, "ТЕКСТ"], …]` |
| склейка | быстрая нарезка «газетных страниц» с человеком, одно слово стоит на месте | `word`, `handle` |
| тумблеры | настройки как на айфоне под лицом, переключатели включаются | `rows: [{text, icon, color, at}]` |

Время (`at`) в секундах от начала видео. Все элементы держатся в безопасной зоне Instagram и не закрывают лицо.
