# /эффекты: 7 эффектов для рилсов в Claude Code

Загружаешь вертикальное видео, где ты говоришь в камеру, пишешь команду и через 1–2 минуты получаешь готовый ролик с эффектом.

| команда | что получится |
|---|---|
| `/эффекты стекло` | стеклянные карточки вокруг тебя: просмотры растут, рендер 4K, плашка «Смонтировал Claude» |
| `/эффекты орбита` | обложки твоих рилсов кружат вокруг головы и уходят за неё |
| `/эффекты прожектор` | комната гаснет, ты в свете, за головой загорается неоновое слово |
| `/эффекты чеклист` | рядом с тобой список, который сам отмечается галочками |
| `/эффекты таймлайн` | монтажная панель с бегущей светящейся линией |
| `/эффекты склейка` | быстрая нарезка «газетных страниц» с тобой, одно слово стоит на месте |
| `/эффекты тумблеры` | переключатели как на айфоне включаются под лицом |

Все надписи держатся в безопасной зоне Instagram и не закрывают лицо.

## Что нужно

- **Claude Code** (тариф Claude Pro или выше): приложение Claude для компьютера, вкладка **Code**, или Claude Code в терминале.
- Mac (проверено на macOS). На Windows и Linux может заработать, но не проверялось.
- Если на компьютере нет **Node.js** и **ffmpeg**, Claude подскажет, как их поставить, или поставит сам по твоей просьбе.

## Установка

### Вариант 1. Попроси Claude (самый простой)
Открой новый чат во вкладке Code и вставь:

> Установи скилл «эффекты»: скачай репозиторий https://github.com/merkulovalanass-png/claude-effects и скопируй папку `plugins/effects/skills/эффекты` в `~/.claude/skills/эффекты`.

После этого в новом чате работает команда `/эффекты`.

### Вариант 2. Как плагин
В Claude Code выполни по очереди:
```
/plugin marketplace add merkulovalanass-png/claude-effects
/plugin install effects@claude-effects
```
В этом случае команда называется `/effects:эффекты`.

## Как пользоваться

1. Перетащи видео в поле ввода.
2. Напиши, например, `/эффекты прожектор`.
3. Готовое видео появится в чате и сохранится рядом с исходным файлом: «<имя> — прожектор.mp4».

Тексты можно менять своими словами: `/эффекты прожектор, слово МАРИНА` или `/эффекты склейка, слово на плашке КЛИП, ник my.blog`.

**Первый запуск дольше (2–4 минуты):** Claude один раз ставит движок анимации, а для «орбиты» и «прожектора» ещё и вырезку человека из фона. Дальше каждый эффект занимает 1–2 минуты.

**Свои настройки по умолчанию** лежат в файле `~/.effects/config.json`:
```json
{"spotlight": {"word": "МАРИНА"}, "matchcut": {"handle": "my.blog"}, "covers_dir": "~/Pictures/обложки"}
```
Для «орбиты» положи обложки своих рилсов (картинки или видео) в папку `covers_dir`. Без неё на обложках будут кадры из самого видео.
